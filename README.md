## The entry

## How it works

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), checks it against the 140-character gate before writing, then reads it back and verifies it byte-for-byte.
